# Solar System Explorer (Star Map)

A high-performance, minimalist, and visually immersive space education web application designed specifically for toddlers (Ages 2-5).

## 🚀 Concept
The Solar System Explorer is built with a **"Toddler-First" UX philosophy**. It removes all traditional UI clutter (menus, buttons, ads) and replaces it with a pure, sensory-driven interaction model. The goal is to encourage celestial body recognition and phonetic mimicry through high-contrast visuals and consistent, high-quality narration.

## ✨ Key Features
- **Vibrant 3D Stylized Visuals**: Custom-generated, hyper-realistic 3D planets designed with high contrast and volumetric glows to capture a toddler's attention.
- **Consistent Audio Narration**: 26 high-quality, pre-recorded "Soft Mature Woman" voice files in both **Bahasa Indonesia** and **English**. This ensures a gentle, consistent learning experience across all devices.
- **Sensory Feedback Loop**: 
    - **Interactive Bounce**: Planets pulse and react to touch.
    - **Spatial SFX**: Cinematic "Whoosh" sounds on swipe and "Magic Sparkle" sounds on tap.
- **PWA (Progressive Web App)**: Can be installed on any tablet or phone home screen to run in **Standalone Full-Screen Mode**, creating a safe, distraction-free sandbox.
- **Butter-Smooth Performance**: Optimized with hardware acceleration (GPU) and asset preloading to ensure zero lag on mobile devices.

## 🛠 Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Animations**: Framer Motion (Spring-based physics)
- **Styling**: Tailwind CSS 4
- **Deployment**: GitHub Pages via Automated GitHub Actions
- **PWA**: Web App Manifest & Service Worker ready

## 📱 Optimization
- **Responsive Design**: Dynamically scales images to occupy 85-95% of the viewport for maximum impact on tablets and phones.
- **Static Export**: Built as a fully static site (`output: export`) for instantaneous loading and offline-ready capabilities.
